【更新后工作流跑不通怎么办】
· 按 W 打开面板 → 右上角点「从面板导入」→ 再点「发送到面板」，能解决大部分问题。
· wd14 目录内的文件，重新复制到 ComfyUI 插件目录的 ComfyUI-WD14-Tagger 目录，替换同名文件。
· 26-7-22以后的版本可以不替换wd14插件的文件,但考虑到旧的工作流用到了wd14节点,暂时保留.

【清空输入 / 清空输出按钮】
· 中间工具条下方有「清空输入」和「清空输出」两个按钮，点击后有 5 秒确认时间，再次点击会清空 ComfyUI 目录下 input 或 output 里的文件，用于快速清理垃圾文件。
· 建议：喜欢的图按 F 键直接下载，不喜欢的就别按，按 G 生成下一个，这样不用再去输出目录挑图。

■ 26-10-4
  保存图像节点(BSK_SaveImage) 文件名前缀新增 时间/时间戳 支持(此前官方只支持 %year% %month% 等固定占位符, 不支持自定义格式和时间戳):
    1. %date:<格式>% 自定义日期时间, 格式符可任意组合: yyyy/yy 年, MM/M 月, dd/d 日, HH/H 24时, hh/h 12时, tt AM/PM, mm/m 分, ss/s 秒, fff/ff/f 毫秒; 例如 %date:yyyy-MM-dd_HH-mm-ss% 得到 2026-10-04_18-25-12, %date:yyyy年MM月dd日% 得到 2026年10月04日,
    2. 中文「时间」自动判定为 2 位年-月-日 (如 26-10-04), 中文「时间戳」自动判定为 10 位秒级 unix 时间戳 (如 1791109512),
    3. %timestamp% / %timestamp_s% 为 10 位秒级 unix 时间戳, %timestamp_ms% 为 13 位毫秒级时间戳,
    4. 前缀中的其余字符(- _ . : 空格 中文等)原样保留, 官方 %year% %month% %day% %hour% %minute% %second% %width% %height% 仍可混用,
    5. 单次执行内时间只取一次, 批量出图共用同一时间, 不影响文件名末尾序号的递增逻辑,

────────────────────────────────────────────────────────
  训练功能简要说明
────────────────────────────────────────────────────────

1. 先克隆 sd-scripts 项目到与 ComfyUI 同级的目录。
   例如 ComfyUI 在 d:\ai\ComfyUI：
       cd d:\ai
       git clone https://github.com/kohya-ss/sd-scripts
   最终目录结构：
       d:\ai
         ├─ ComfyUI
         └─ sd-scripts

2. 在终端里激活 ComfyUI 的虚拟环境，cd 到本插件目录 ComfyUI-bsk_UI，执行：
       pip install -r requirements.txt
   （或用 ComfyUI 环境中的 python 调用 pip 安装，不懂可以问 AI。）
   作用是补齐 sd-scripts 需要的依赖，已测试过与 ComfyUI 的依赖没有冲突。
   不想手动安装的话，训练面板里也有一键安装依赖的按钮（未充分测试，效果不保证）。

3. 使用步骤（非常简单）：
   ① 右上角选第一步「素材」，左上角点加号「添加子目录」，命名规则为「重复次数_触发词」（如 1_触发词，也可用 2_ 等），可添加多个目录。
   ② 点击子目录，拖拽图片到中间区域，点右上角「打标」按钮。
   ③ 切换到第二步「参数」，设置好参数（默认 Anima LoRA，默认参数基本能用，不懂可问 AI）；在下方「样本提示词（sample_prompts）」里输入生成预览图用的提示词。
   ④ 在顶部右上角点击「开始训练」。
   ⑤ 训练监控的内容看一下就明白了；训练失败时日志中会有详细信息，复制给 AI 能解决大部分问题。
